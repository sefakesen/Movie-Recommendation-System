# 🎬 Movie Recommendation System (Film Öneri Sistemi)

Bu proje, C# ve Windows Forms kullanılarak geliştirilmiş, kullanıcılara içerik tavsiyelerinde bulunan bir masaüstü uygulamasıdır. 

## 🚀 Özellikler
* **Film Önerileri:** Kullanıcının zevkine uygun film tavsiyeleri sunan algoritma altyapısı.
* **Favoriler Sistemi:** Kullanıcıların izlemek istedikleri veya beğendikleri filmleri kişisel veri tabanlarına kaydetme imkanı.
* **Kullanıcı Dostu Arayüz:** Windows Forms ile tasarlanmış sade ve anlaşılır görsel tasarım.

## 🛠️ Kullanılan Teknolojiler
* **Programlama Dili:** C# (.NET Framework)
* **Arayüz Tasarımı:** Windows Forms Application
* **Veri Yönetimi / Depolama:** CSV (Comma-Separated Values) Dosya Formatı
* **Dosya İşlemleri:** `System.IO` (Veri okuma, yazma ve veri tabanı gibi simüle etme işlemleri için)

## ⚙️ Kurulum ve Çalıştırma
Projeyi kendi bilgisayarınızda çalıştırmak için şu adımları izleyin:
1. Bu repoyu bilgisayarınıza klonlayın: `git clone https://github.com/sefakesen/Movie-Recommendation-System.git`
2. `MovieRecommendationSystem.sln` dosyasını Visual Studio ile açın.
3. F5'e basarak projeyi derleyin ve çalıştırın.
